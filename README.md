# LFG Languages Forever

Search for groups and players listed in multiple languages in WoW Forever 1.60.1.

1. Extract the `LFGLanguagesForever` folder from the release ZIP into the Forever client's `Interface/AddOns` folder and enable it in the AddOns list. For a source checkout, create that folder and copy the root `.toc` and `.lua` files into it.
2. Open **Group Finder → Browse**, then choose a category and, optionally, activities.
3. Click the **Options** gear in the upper right, open **Languages**, and tick the languages you want.
4. Once the current Browse search finishes, click **Search Again**, the refresh button beside the activity dropdown. You can also click **Search** in the Languages submenu. The results appear in the Browse list.

Your game's language is always included. **Select all** includes every language the game offers. **Unselect all** returns to your game's language by itself. Blizzard's automatic Browse searches use the game's default languages. Click **Search Again** or the submenu's **Search** to apply your saved selections.
